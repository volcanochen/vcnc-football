# VCNC足球 v0.5.0

**当前推荐版本**。本版是**集锦交互打磨 + 首页更抗风控**批次：集锦浮窗在「集锦 / 全场」
两个 tab 里都能用，起点终点按钮直接显示时间，编辑时临时进入完整原片、退出后回到原模式，
慢动作三档改成 ½ / ¼ / ⅛ 分数图标；同时把首页投稿流换成对游客更宽松的 B 站接口，
新装、未登录、新 IP 打开就能出片。播放引擎、缓存、流量统计、账号社交与风控韧性沿用 v0.4.0。

## 新增

### 集锦交互四项调整
- **两个 tab 通用**：自定义片段（和官方片段）在「集锦」「全场」两个 tab 的浮窗里都在，
  不因切 tab 消失；全场 tab 点行直接在当前整场画面上 seek 到片段起点，不切段、不重建序列，
  高亮跟着画面当前时间走。
- **起点/终点显示时间戳**：按钮点亮后直接写「起点 4:02」「终点 4:19」，
  不用再靠提示或保存按钮悬停回味区间。
- **编辑态临时进入完整原片**：打开工作室后可以在整场时间轴里自由穿过片段边界，
  单指快拖按整场时长钳制，进度条标注「编辑（整场）」；保存只重算片段与浮窗，
  不会把正在自由播放的画面拦腰打断；退出时按当前画面时间归位到对应片段，
  进入前是暂停就仍暂停。**全程不改设置里的播放模式**，退出后原模式不变。
- **慢动作改分数按钮**：三档从 `0.5× / 0.25× / 0.125×` 改为内联 SVG 分数 ½ / ¼ / ⅛，
  与其它图标按钮统一 36px 方形，再点恢复常速与选中态都不变。

### 首页投稿流换数据源（B 站风控）
- 首页列表从空间动态接口 `x/polymer/web-dynamic/v1/feed/space` 换成
  `x/series/recArchivesByKeywords`。前者对游客已收紧：不带 cookie 直接 412，
  带了 buvid 也只回空 items（软风控），新装 / 新 IP 上表现为「空白列表」；
  新接口无 cookie 裸请求即 `code=0`，稳定返回 30 条一页，翻页按页码推进。
- 分页契约、足球过滤、5 分钟分页缓存、风控断路器与冷却期零请求全部保留；
  桌面调试服 `server.py` 与 Android 端 `BiliApi.java` 同步改到同一语义。

## 变化

- 首页时长字段改为由接口的秒数统一格式化（`M:SS` / `H:MM:SS`），不再依赖动态接口的文本字段。
- **时间码自动校准更稳**：OCR 改用「最靠下的合法连续行段」定位画面时钟，之前画面下缘的
  草皮高光/灯光亮点会把数字行带撑到 55+ 行而被整帧放弃；同时采样点从 3 个放宽到最多 5 个
  有效样本并取最优三元组拟合，单帧被球员/灯光挡住或误读不再导致整场放弃校准
  （典型表现：某些比赛一开场就「校准失败」，评论时间戳直接 seek 会有 1~3 秒漂移）。
- 发布门禁新增/更新契约检查：集锦编解码 47 项、真机集锦 21 项。

## 安装 / 升级

下载本页 `VCNC-Football-v0.5.0.apk` 覆盖安装，或在应用内点「设置 → 软件更新 → 检查更新」升级。
与之前所有版本**同一签名**（证书 SHA-256 `e1a8d88b…`），可直接覆盖。
Android 8 及以上首次安装需允许本应用「安装未知应用」。

包名 `com.vcncfootball`，versionCode 10 / versionName 0.5.0，minSdk 24 / targetSdk 34，V3 签名。
校验和见仓库 `release/SHA256SUMS.txt`。源码与文档：<https://github.com/volcanochen/vcnc-football>

## 验证

- **发布门禁**：静态检查与双机真机回归按 [发布门禁](../docs/RELEASE_GATE.md) 全量执行，
  结果见该文档「执行记录」。
- **免设备回归**：集锦编解码 `_test/verify_clips_codec.js`、风控韧性
  `_test/verify_risk_guard.py`、分享 H5 中转页与二维码矩阵。
- **真机**：S22U 与 Note8 在**卸载后全新安装**（无 cookie、无缓存、无旧版数据）的场景下
  验证：首页出片 30 条 → 自动解析 → 正常播放；冷启动偶发一次 HTTP 412 时，
  断路器按设计冷却，列表仍能拿到，冷却结束后解析与播放恢复。

## 已知限制

- 大会员档位（1080P60 / 高码率 / 4K）仍需大会员账号，非会员点选时 B 站自动降级。
- 若出口 IP 正处于 B 站风控窗口，接口可能返回「降级流」或要求等待冷却；
  这是 B 站侧的软限制，换出口 IP（WiFi / 蜂窝）或等窗口冷却即恢复。
- 发布到评论区的自定义片段依赖 B 站评论接口：B 站删评 = 云端丢失（本地仍保留）。
- S22U（400px 宽）顶部标题空间依旧紧张，超长标题会出现省略号。
