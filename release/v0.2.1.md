# VCNC 足球沉浸场 v0.2.1

v0.2.0 的下载修复版。**建议所有用户升级到本版本**：v0.2.0 在部分网络下能检查到更新、却下载不了 APK。

## 问题与修复

真机（Galaxy Note8 / Android 9）实测：`api.github.com` 可达，所以「检查更新」正常；
但 `github.com:443` 连接超时，`releases/download` 资产下载必然失败：

```
更新失败：下载失败：failed to connect to github.com/20.205.243.166 (port 443) ... after 15000ms
```

`UpdateChecker` 改为**多源顺序回退**，任一成功即安装：

1. Release 官方 `browser_download_url`（正常网络最快）
2. jsDelivr CDN 三个域名：`cdn / fastly / gcore.jsdelivr.net`，指向仓库 `release/` 下同名 APK
3. `api.github.com/repos/.../contents/release/<apk>?ref=<tag>`，用 base64 返回文件内容
   —— 走已确认可达的 API 域名，不依赖 CDN

同时加了 **APK 魔数校验**（zip `PK` 头），避免把错误页 / HTML 当安装包交给系统安装器；
下载超时缩短到 8s 连接 / 25s 读取，单个源失败立即切下一个，失败信息列出各源原因。

## 前提条件（发布侧）

每个 Release 的 APK 必须**同时**提交到仓库 `release/` 目录并保持同名，
后两个备用源才有东西可取。发布流程见 `release/README.md`，脚本已保证这一点。

## 其余功能

与 v0.2.0 相同：VCNC 比赛流、集锦连播、焦点镜头与竖屏分屏放大镜、
集锦分类、慢动作、亮度/音量手势、冷启动续播、应用内更新。

## 安装 / 升级

下载本页 `VCNC-Football-v0.2.1.apk` 直接覆盖安装（与 v0.2.0 同一签名），
或在 v0.2.0 应用内点「检查更新」→「下载并安装」。
Android 8+ 首次需在系统设置里允许本应用「安装未知应用」。

包名 `com.vcncfootball`，versionCode 3 / versionName 0.2.1，minSdk 24 / targetSdk 34，V3 签名。
校验和见仓库 `release/SHA256SUMS.txt`。
