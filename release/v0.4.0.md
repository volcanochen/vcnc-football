# VCNC足球 v0.4.0

**当前推荐版本**。本版是**自定义集锦 + 更耐用的网络**批次：你可以在任何一场里自己
圈精彩片段、保存到本机、发布到评论区跟别人共享，还能生成分享码发给微信好友一键导入；
同时把 B 站风控的应对整个重做过——IP 被限流时不再白屏报错，已缓存的比赛照常能看。
播放引擎与倒放、缓存、流量统计沿用 v0.3.0。

## 新增

### 自定义集锦（左下浮窗「＋制作」）
- **自己圈片段**：浮窗里点「＋制作」进入工作室，选起点、终点，或直接点预设
  （进球 / 危险进攻等）一键生成；可加备注。保存后即刻插入本场连播清单，
  与官方集锦混排播放。
- **片段分色**：自己做的片段整行青色、别人发布的是紫色、官方仍是白色/灰色，
  左侧带色条一眼可辨；点行内文字可直接编辑时间、时长与备注。
- **只看自定义**：工具行「自定义」开关只显示自己创建的片段；筛选开启时
  「切下一条」也只在自定义片段里推进。
- **评论区云同步**：把片段发布到该视频的评论区（增量模式只发新增片段，
  全量模式整份重发一条，都不动别人和自己的旧评论）；别人发布的片段会自动
  出现在你的浮窗里。B 站删评论 = 云端丢失，本地仍保留。
- **微信分享**：每条片段可生成 `VC1` 分享码，复制发给好友，或走 H5 中转页
  （<https://volcanochen.github.io/vcnc-football/share/>）跳回应用一键导入。

### 非线性快拖进度
- 单指横拖进度条：半屏以内线性精调，拖过半屏后**速度二次加速**，
  快速跨段跳到不同的进度；落点自动钳在段尾前，不会出现「拖的是这段、
  播的却是下一段」。

### 画质档位人人可点
- 360P~1080P 的切换**不再要求大会员**，未登录也能点选；
  1080P60 / 高码率 / 4K 等大会员档同样可点，B 站会自动下发账号可见的最高档。
- 高亮跟随**实际播放画质**：点高档却被 B 站降级时，高亮落在真实拿到的档位上，
  一眼看清。切换仍会记住播放进度并短暂重载。

### B 站风控韧性（后台自动，无需操作）
- 统一识别 B 站风控信号（-352/-412/-403/-509、HTTP 412/429 等），命中后进入
  **阶梯冷却**（30/60/120/300 秒），冷却期内不再发任何上游请求，不会越打越封。
- **view / playurl / 评论整条解析链共用登录凭证**，并修掉旧版重复使用过期
  wbi 签名的问题。
- 每次解析成功都会留存一份**解析快照**：被风控时自动回放缓存结果，
  已缓存过字节的比赛**完全离线可播**，页面给出明确的降级提示与重试等待时间，
  不再是干巴巴的报错。

## 变化

### 集锦浮窗与工作室
- 浮窗自动隐藏收紧到 **2 秒**；宽度收窄到 106px，低分辨率直屏（≤380px 宽）
  强制 94px 并隐藏序号列，保证内容可读。
- 工具行精简为「＋制作 / 自定义」两个按钮，云同步与导入自动完成，不再单独占位；
  工作室面板与播放画面**同一层**，比赛列表 / 设置页 / 登录弹层出现时自动退场。
- 制作面板去掉步骤编号，直接是起点 / 终点 / 预设 / 备注 / 保存。

## 安装 / 升级

下载本页 `VCNC-Football-v0.4.0.apk` 覆盖安装，或在应用内点「设置 → 软件更新 → 检查更新」升级。
与之前所有版本**同一签名**，可直接覆盖。
Android 8 及以上首次安装需允许本应用「安装未知应用」。

包名 `com.vcncfootball`，versionCode 9 / versionName 0.4.0，minSdk 24 / targetSdk 34，V3 签名。
校验和见仓库 `release/SHA256SUMS.txt`。源码与文档：<https://github.com/volcanochen/vcnc-football>

## 验证

- **发布门禁全绿**：静态检查（版本一致性 / 语法与 Chrome 74 红线 / 品牌资源 /
  APK 内容与签名 / 文档链接 / 两端流量与社交接口对齐 / 集锦编解码与 H5 中转页）
  与双机真机回归全部通过。
- **免设备回归**：分享码编解码 `_test/verify_clips_codec.js` 36/36；
  微信 H5 中转页 11/11；二维码矩阵 32/32；风控韧性 `_test/verify_risk_guard.py` 44/44。
- **真机**：集锦本地制作 / 云同步 / 筛选推进 / 行内编辑在双机通过验收；
  非线性快拖速度曲线、跨段落点与「拖 A 播 A+1」回归全绿；
  风控冷却期内 `/api/resolve` 确认 0 上游请求、快照回放可播。
- **已知现场限制**：若 IP 正处于 B 站风控窗口，接口可能返回「降级流」
  （请求 1080P 实际下发 480P）——这是 B 站侧的软限制，等窗口冷却即自动恢复，
  与登录或会员状态无关。

## 已知限制

- 大会员档位（1080P60 / 高码率 / 4K）仍需大会员账号，非会员点选时 B 站自动降级。
- 发布到评论区的自定义片段依赖 B 站评论接口：B 站删评 = 云端丢失（本地仍保留）；
  评论区风控期间发布会自动退避，稍后再试。
- S22U（400px 宽）顶部标题空间依旧紧张，超长标题会出现省略号。
