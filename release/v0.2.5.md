# VCNC足球 v0.2.5

**当前推荐版本**。本版是**品牌化 + 分享 + 流量可视化**批次：全新应用图标与正式命名、
设置页改成「分享与支持」、新增网络流量统计，并把文档体系拆成用户说明 / 技术文档 /
开发历史三份，同时建立发布门禁。播放引擎沿用 v0.2.4（含倒放 v6.1、点段精确落段等修复）。

## 新增

### 应用图标与名称
- 全新 launcher 图标：绿茵渐变球场 + 斜向草坪条纹 + 中央白色足球 + 四角青色取景框
  （呼应「自动跟焦」）。纯代码绘制，产出 5 档密度方形/圆形图标与 Android 8+ 自适应图标。
- 正式命名：中文 **VCNC足球**，英文环境 **VCNC football**。系统按语言自动切换，
  两台真机应用详情页均已确认中文名与新图标生效。

### 设置页「分享与支持」
- 原来的「▶ 回到播放」与底部说明文字整块移除，返回入口移到设置页顶部「‹ 播放」。
- 新增：应用图标与名称、**最新版下载二维码**（扫码打开下载页）、一键分享、
  复制链接、下载页、VCNC 的 B 站空间、GitHub 主页、GitHub Issues、B 站私信，
  以及**微信打赏码**（免费无广告，欢迎支持作者）。
- 联系方式按公开渠道处理：GitHub Issues 与 B 站私信，不公开私人邮箱/微信号。
- 外部链接通过新增的三个原生桥交给系统浏览器 / 分享面板 / 剪贴板，不会把 WebView 跳走。

### 网络流量消耗提示
- 播放页左上角常驻小胶囊：`↓ 当前网速 · 本次已用`；使用**移动数据**时变橙并写明「移动数据」。
- 设置页「网络流量」：当前速度、本次启动消耗、安装以来累计消耗、**缓存已省流量**，可一键清零
  （只清统计数字，不删缓存文件）。
- 口径：只统计真正从 B 站下载的字节（接口 + 视频流 + 集锦预取 + 透传）；
  App 内部回环通信与本地缓存命中都不计入，后者单列为「已省」。
  累计值跨重启保留，实测 Note8 累计缓存已省 214 MB。

## 安装 / 升级

下载本页 `VCNC-Football-v0.2.5.apk` 覆盖安装，或在应用内点「设置 → 软件更新 → 检查更新」升级。
与之前所有版本**同一签名**，可直接覆盖；桌面图标名称会变为「VCNC足球」。
Android 8 及以上首次安装需允许本应用「安装未知应用」。

包名 `com.vcncfootball`，versionCode 7 / versionName 0.2.5，minSdk 24 / targetSdk 34，V3 签名。
校验和见仓库 `release/SHA256SUMS.txt`。源码与文档：<https://github.com/volcanochen/vcnc-football>
