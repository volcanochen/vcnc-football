# VCNC 足球沉浸场 v0.2.0

首个独立发布的版本。此前这个方向只作为 `volcanochen/H-Player` 的 `vcnc-football` 试验分支存在，
从未推送、也未发布；本次拆为 `volcanochen/vcnc-football` 单独维护，并接上应用内更新通道。

## 这个应用做什么

打开就是 VCNC（B 站 mid 432185343）五人制足球的竖滑比赛流：只播集锦、自动无缝连播，
镜头自动追随球与持球人平滑放大。竖屏时上半屏保留完整画面，下半屏是跟焦放大镜。

## v0.2.0 新增

- **应用内更新**：设置 → 「检查更新」→ 读本仓库 GitHub Releases 的最新版 →
  显示版本号与更新说明 → 下载 APK → 调起系统安装器升级。
  版本按语义版本比较，只在 Release 附带 APK 时提示；后续升级不再需要连电脑 adb。
- 独立仓库、独立 README 与发布目录 `release/`；构建脚本工具链路径改为可用环境变量覆盖。
- 版本号从 `0.1.0` / versionCode 1 提升到 `0.2.0` / versionCode 2。

## 主要功能

- UP 主动态 feed 拉取 + 足球关键词过滤，竖滑切场、上拉加载更多
- 置顶评论时间戳 → 集锦片段，双 deck 预热硬切连播；可按动作码筛选（进球/助攻/过人/…）或切原片
- 焦点镜头：帧差 + 球场/球门/人员/球识别 → 持球者与球→门预测 → 平滑追随放大（1.15×~2× 可调）
- 竖屏分屏放大镜、焦点框、球圈、算法可视化、双指捏合缩放与临时移焦
- 左下角播放/暂停与 `0.5×` / `0.25×` / `0.125×` 慢动作；左半屏滑亮度、右半屏滑音量；本场播完停住
- 冷启动续播（按 bvid + 片段 + 进度）、feed 本地缓存兜底、可选登录 Cookie

## 安装 / 升级

1. 下载本页的 `VCNC-Football-v0.2.0.apk`。
2. Android 8+：首次安装或应用内更新前，在系统设置里允许本应用「安装未知应用」。
3. 已装 v0.1.0 且为同一签名的，可直接覆盖安装。

包名 `com.vcncfootball`，minSdk 24 / targetSdk 34，V3 签名。校验和见仓库 `release/SHA256SUMS.txt`。

## 已知限制

- 端侧自研球检测在真实 854×356 低清源上不可靠，正式效果依赖 PC 预计算轨迹
  （由 [`volcanochen/FootballTracking`](https://github.com/volcanochen/FootballTracking) 产出，
  经 `/api/tracks/<bvid>.json` 下发）；该仓库较新的 `track_v2` / BallTracer 成果尚未回灌端侧。
- B 站游客请求有 -352 风控，加载失败时可在设置里填 `SESSDATA`。
- 真机验证主要在 Galaxy Note8 / Android 9 完成；目标 WebView 为 Chrome 74。

## 校验

- APK 使用项目私有签名（keystore 别名 `bilihl`），私钥不入库；同一签名保证后续版本可覆盖升级。
