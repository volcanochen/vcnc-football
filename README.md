# VCNC足球（VCNC football）

一款只看 **VCNC 五人制足球** 的 Android 沉浸播放器。打开就是比赛流，自动把一场录像里的精彩片段拼成一条连播清单，镜头还会跟着球放大。免费、无广告、不收集个人信息。

<img src="static/app-icon.png" width="96" alt="VCNC足球 应用图标">

> 当前版本 **v0.2.5**（试验版，未上架应用商店）。需要 Android 7.0 及以上。
>

## 它解决什么问题

在手机上看一场 70 分钟、854×356 的低清五人制全场录像，通常有三件烦心事：

| 痛点 | 本应用怎么做 |
|---|---|
| 球只有 3~8 个像素，眼睛根本找不着 | 镜头自动追着球 / 持球人平滑放大；竖屏还能上半屏看全场、下半屏看放大镜 |
| 精彩镜头散落在整场录像里，得反复拖进度条 | 自动读取作者在置顶评论里标的时间戳，**只播集锦**，段与段之间无缝衔接、没有加载圈 |
| 想看清一个进球或过人，一晃就过去了 | 单段循环、三档慢动作、倒放逐帧回看，还能双指缩放自己取景 |

一句话：**把「找球 + 找片段 + 反复回拉」这三件事自动化，只留下看球本身。**

## 主要特点

- **集锦自动连播**：从置顶评论解析片段时间轴，两台播放器交替预热硬切，看完一段直接进下一段；本场播完会停住，不会自作主张跳到下一场。
- **镜头跟着球走**：起播前预读画面算出焦点轨迹，播放时平滑缓动追随放大（1×~3× 可调，也能关掉）；支持竖屏分屏，上窗完整画面 + 下窗放大镜。
- **看得清每一个细节**：`0.5×` / `0.25×` / `0.125×` 慢动作、正放/倒放一键切换、单段循环、双指捏合缩放与平移。
- **片段浮窗**：右侧半透明窄条列出本场全部片段，点哪行跳哪段，当前段高亮并自动滚到可见；标题可切「集锦 / 全场」，可收起。
- **时间码对齐**：B 站转码会让画面上烧录的时钟与播放进度慢慢错开，应用会自动校准并把片段标签对齐到「画面上真正看到的时刻」，还自动给每个片段补上前后几秒，不会切掉动作起手。
- **按字符筛片段**：在备注里输入任意字符（如 `g`、`!`、`进球`）只播含这些字符的片段，下方自动统计本场出现的字符，一键点选。
- **省流量**：看过的视频/音频字节落盘（默认 600MB 上限），关掉 App 再打开同一场直接从本地读；解析成功还会后台把本场全部集锦预取好。播放页实时显示当前网速与本次流量，设置页显示累计消耗和「缓存已省」，移动数据下会高亮提醒。
- **断网与风控兜底**：比赛列表本地缓存，接口受限时退避重试并沿用上次结果；可选填登录 Cookie 提高配额。
- **应用内更新**：设置页一键检查 GitHub 新版本、下载并调起系统安装器；下载线路多源自动回退。
- **续播记忆**：冷启动回到上次那场比赛的片段与进度。

## 怎么安装

三种方式任选其一：

1. **扫码下载**：用手机扫下面这张二维码，直接打开最新版下载页。
2. **打开下载链接**：<https://github.com/volcanochen/vcnc-football/releases/latest>，下载其中的 `.apk`。
3. **应用内升级**：已装旧版 → 设置 → 软件更新 → 检查更新 → 下载并安装。

<img src="static/share-qr.png" width="180" alt="最新版下载二维码">

安装注意：

- Android 8 及以上，首次安装需在系统弹窗里允许本应用「安装未知应用」。
- 覆盖升级请使用同一个仓库发布的 APK（签名一致）；若提示「应用未安装」，先卸载旧版再装。
- 应用本身不申请通讯录、位置、短信等权限；只用网络与安装权限。

## 怎么使用

### 三个页面

| 页面 | 怎么进 | 怎么回播放 |
|---|---|---|
| **播放**（默认） | 打开应用即进入 | — |
| **比赛列表** | 播放页右上角「列表」 | 列表右上角 `▶`，或系统返回键 |
| **设置** | 播放页右上角「设置」 | 设置页左上「‹ 播放」，或系统返回键 |

播放页按系统返回键第一次会提示「再按一次退出」，两秒内再按才退出，避免误触。

### 播放页操作

| 操作 | 效果 |
|---|---|
| 点一下画面 | 暂停 / 继续，并唤出控制条；**正在拖动进度条、滚列表或按住按钮时不会自动隐藏** |
| 左下角控制条 | 播放/暂停、正放/倒放方向切换、单段循环、跟踪球、三档慢动作 |
| 右侧集锦浮窗 | 点行跳到该片段；标题切「集锦 / 全场」；`›` 收起成小把手 |
| 左半屏上下滑 | 调屏幕亮度 |
| 右半屏上下滑 | 调音量 |
| 单指左右滑 | 快进 / 回退（拖满一屏约 ±90 秒），带时间气泡预览 |
| 双指捏合 / 拖动 | 自定义缩放与平移，松手后保持；想恢复自动跟焦点「跟」或到设置里重开 |
| 拖动底部进度条 | 精确 seek |

控制条 3 秒无操作会自动淡出，播放键常驻；再点一下画面即可唤回。

### 常用设置

| 设置 | 说明 |
|---|---|
| 播放内容 | 集锦连播 / 原片（整场录像） |
| 画面填充 | 「完整」按比例显示全部、上下留黑边；「铺满」填满屏幕但会裁掉两侧 |
| 集锦分类 | 按备注字符筛选，留空 = 全部 |
| 自动补时 | 自动按校准结果给片段前后各补 1.5~3 秒；也可手动调 0~15 秒 |
| 自动跟焦 / 缩放倍率 | 镜头是否追球、放大到多少 |
| 竖屏分屏 / 焦点框 / 算法可视化 | 分屏放大镜、识别框与算法调试叠加层 |
| 缓存上限 / 缓存占用 | 200M / 600M（默认）/ 1G / 2G，实时占用与命中数，一键清空 |
| 网络流量 | 当前网速、本次与累计消耗、缓存省下的流量，可清零 |
| 登录 Cookie | 可选填 `SESSDATA`，提高接口配额 |
| 软件更新 | 检查 / 下载安装新版本 |
| 分享与支持 | 应用二维码、下载与项目链接、联系方式、微信打赏码 |

## 流量与缓存

- 播放页左上角常驻一个小提示：`↓ 当前网速 · 本次已用流量`。使用**移动数据**时会变成橙色并写明「移动数据」，提醒注意套餐。
- 设置页「网络流量」给出三个口径：**当前速度**、**本次启动消耗**、**安装以来累计消耗**，以及**缓存已省下多少流量**；点「清零」只清统计数字，不删缓存文件。
- 只统计真正从网络下载的字节；命中本地磁盘缓存、以及 App 内部通信都不计入。
- **省流量用法**：第一次打开某场比赛时连 WiFi，让它把集锦片段缓存好；之后用移动数据甚至短时断网重看同一场，基本不再走流量。默认 600MB 足够留住近十场比赛的集锦数据。

## 常见问题

**第一次打开很慢，或提示「接口受限」？**
比赛列表和片段信息来自 B 站公开接口，偶发风控限流。应用会自动退避重试并沿用本地缓存；稍后再点列表里的「重试」，或在设置里填 `SESSDATA` 提高配额即可。

**列表里比赛不全？**
默认只加载第一页，滚到列表底部点「加载更多」。

**浮窗时间码和画面上的时钟对不上？**
B 站转码会把可变帧率重排成恒定帧率，烧录时钟与播放进度每小时会漂几秒。应用会自动做时间轴校准，并把浮窗标签显示成「起播那一刻画面上的时间」，所以两者本就不该是同一个数字；想微调可用设置里的前置/后置补时。

**画面卡住不动、只有声音？**
超高像素的折叠屏会自动切到单路解码模式；若仍异常，到设置里关掉「算法可视化」、把画面填充切回「完整」，或点「恢复完整显示」。

**装不上 / 更新下载失败？**
确认系统允许本应用「安装未知应用」，且用的是本仓库发布的同一签名 APK。下载线路会自动在官方资产、CDN、GitHub 接口之间回退，仍失败可直接在浏览器打开下载链接。
