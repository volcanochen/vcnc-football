# VCNC足球（VCNC football）

一款只看 **VCNC 五人制足球** 的 Android 沉浸播放器。打开就是比赛流，自动把一场录像里的精彩片段拼成一条连播清单，镜头还会跟着球放大。免费、无广告、不收集个人信息。

> 当前版本 **v0.4.0**（试验版，未上架应用商店）。需要 Android 7.0 及以上。
>
> 本版新增：**自定义集锦**（自己圈片段 / 评论区云同步 / 微信分享导入）、
> **非线性快拖进度**（半屏内精调、拖过半屏二次加速）、**画质档位人人可点**
> （360P~1080P 不需要大会员）；B 站风控应对整个重做，被限流时已缓存的比赛照常可看。
> 详见 [版本发布说明](release/v0.4.0.md)。

## 它解决什么问题

在手机上看一场 70 分钟、854×356 的低清五人制全场录像，通常有三件烦心事：

| 痛点 | 本应用怎么做 |
|---|---|
| 球只有 3~8 个像素，眼睛根本找不着 | 镜头自动追着球 / 持球人平滑放大；竖屏还能上半屏看全场、下半屏看放大镜 |
| 精彩镜头散落在整场录像里，得反复拖进度条 | 自动读取作者在置顶评论里标的时间戳，**只播集锦**，段与段之间无缝衔接、没有加载圈 |
| 想看清一个进球或过人，一晃就过去了 | 单段循环、三档慢动作、倒放逐帧回看，还能双指缩放自己取景 |

一句话：**把「找球 + 找片段 + 反复回拉」这三件事自动化，只留下看球本身。**

## 主要特点

- **集锦自动连播**：从置顶评论解析片段时间轴，两台播放器交替预热硬切，看完一段直接进下一段；本场播完会停住，不会自作主张跳到下一场。
- **镜头跟着球走**：起播前预读画面算出焦点轨迹，播放时平滑缓动追随放大（1×~3× 可调，也能关掉）；支持竖屏分屏，上窗完整画面 + 下窗放大镜。
- **看得清每一个细节**：`0.5×` / `0.25×` / `0.125×` 慢动作、正放/倒放一键切换、单段循环、双指捏合缩放与平移。
- **片段浮窗**：右侧半透明窄条列出本场全部片段，点哪行跳哪段，当前段高亮并自动滚到可见；标题可切「集锦 / 全场」，可收起。
- **时间码对齐**：B 站转码会让画面上烧录的时钟与播放进度慢慢错开，应用会自动校准并把片段标签对齐到「画面上真正看到的时刻」，还自动给每个片段补上前后几秒，不会切掉动作起手。
- **按字符筛片段**：在备注里输入任意字符（如 `g`、`!`、`进球`）只播含这些字符的片段，下方自动统计本场出现的字符，一键点选。
- **自己做集锦**：暂停→选起点→播放→暂停→选终点→写备注（有预设标签），片段和 VCNC 官方集锦混在同一列表、按颜色区分；
  不登录也能做（只存本机，每个视频一份），登录后可发布到该视频的 B 站评论区、每次登录自动读回，还能载入别人的集锦；
  单个片段或整场列表可生成一段分享码，微信里复制粘贴即可导入。
- **B 站账号**：播放页左侧浮窗一行显示头像、昵称与收起箭头；用 B 站 App 授权登录后，**画质档位人人可切**（360P~1080P 不需要大会员；1080P60 / 高码率 / 4K 等大会员档也能点，B 站会自动下发可见的最高档，登录大会员后同档位即生效）。**三连按钮就在标题后面**——未登录是灰的，点一下直接进登录；登录后变亮，点过显示「已三连」，换场次时按该场是否点过自动切状态。凭证只存在手机本机。
- **省流量**：看过的视频/音频字节落盘（默认 600MB 上限），关掉 App 再打开同一场直接从本地读；解析成功还会后台把本场全部集锦预取好。播放页实时显示当前网速与本次流量，设置页显示累计消耗和「缓存已省」，移动数据下会高亮提醒。
- **断网与风控兜底**：比赛列表本地缓存；接口受限时自动冷却并沿用上次结果，已缓存过的比赛改从本地快照 + 磁盘字节回放，全程不再请求 B 站；授权登录后自动携带登录态，接口配额更高（也可在设置里手填 Cookie）。
- **应用内更新**：设置页一键检查 GitHub 新版本、下载并调起系统安装器；下载线路多源自动回退。
- **续播记忆**：冷启动回到上次那场比赛的片段与进度。

## 怎么使用

### 三个页面

| 页面 | 怎么进 | 怎么回播放 |
|---|---|---|
| **播放**（默认） | 打开应用即进入 | — |
| **比赛列表** | 播放页右上角「列表」 | 列表右上角 `▶`，或系统返回键 |
| **设置** | 播放页右上角「设置」 | 设置页左上「‹ 播放」，或系统返回键 |

播放页按系统返回键第一次会提示「再按一次退出」，两秒内再按才退出，避免误触。

### 播放页操作

| 操作 | 效果 |
|---|---|
| 点一下画面 | 显示 / 隐藏控制条与浮窗（不用等自动淡出） |
| 双击画面 | 暂停 / 继续 |
| 左下角控制条 | 播放/暂停、正放/倒放方向切换、单段循环、跟踪球、三档慢动作 |
| 右侧集锦浮窗 | 点行跳到该片段；标题切「集锦 / 全场」；`›` 收起成小把手 |
| 浮窗上的 `＋制作` / `自定义` | `＋制作` 打开自定义集锦工作室（做片段、发布到评论区、载入别人的集锦、从剪贴板导入分享码）；`自定义` 切换成**只看自己创建的片段**，再点恢复全部 |
| 左侧账号浮窗 | 头像 + 昵称一行，下面是画质档位；右上角 `‹` 收起成小把手（展开时箭头朝左） |
| 标题后面的「三连」 | 给本场视频一键三连；灰＝未登录（点它去登录）、亮＝可点、粉色＝已三连 |
| 左半屏上下滑 | 调屏幕亮度 |
| 右半屏上下滑 | 调音量 |
| 单指左右滑 | 快进 / 回退：半屏内线性精调（段内，拖满半屏 ±45 秒），**超过半屏进入加速区**（速度二次拉升，最快约 38×，拖满一屏 ±约 645 秒），可跨段直达全场任意进度，气泡显示落点时间与目标段 |
| 双指捏合 / 拖动 | 自定义缩放与平移，松手后保持；想恢复自动跟焦点「跟」或到设置里重开 |
| 拖动底部进度条 | 精确 seek |

控制条约 2 秒无操作会自动淡出（**正在拖动进度条、滚列表、按住按钮，或 `＋制作` 面板开着时不会自动隐藏**），播放键常驻（且比其他键大一圈）；点一下画面可立即收起，再点一下唤回。倒放键与播放键之间留了一段空隙，避免误触。

### 自定义集锦

不看官方集锦、想自己圈一段也能做到。**不登录就能用**，每场视频各存一份在本机。

1. 播放页右侧集锦浮窗上点 **`＋制作`**，打开工作室。面板里只有五个控件：**起点 / 终点 / 预设备注 / 自定义文字框 / 保存**。
2. 暂停在起点 → 点「起点」→ 继续播放 → 在结束处暂停 → 点「终点」（按钮点亮表示已记下；再点「起点」可重来）。
3. 点一个预设备注（进球 / 射门 / 过人 / 扑救 / 配合 / 抢断 / 争议 / 精彩）或在文字框里自己写，点「保存」。
4. 片段立刻出现在右侧浮窗里，和 VCNC 官方集锦按时间混排、一起连播；**自定义片段整行文字换色**（青绿＝我·本机，蓝紫＝我·云端，橙黄＝别人·已载入），官方片段保持默认白/灰。
5. 想只看自己做的，点浮窗上的 **`自定义`**；再点一次恢复全部。筛选开启时连播推进和「切下一条」也只在你的自定义片段里走，官方片段全部跳过。制作面板只属于播放页——切到比赛列表 / 设置页、或登录界面弹出时它自动让位，不会挡住任何全屏界面，切回来还在原处。
6. 工作室「本场片段」列表里，点某一行上的**文字**可以直接编辑这一段的**起点 / 时长 / 备注**；行尾的分享按钮把单个片段发出去。

**云端**：登录后工作室里有两种发布方式，**都不会动旧评论**——「增量发布」只把没发布过的新片段发成一条新评论（之前发过的自动剔除），「全量发布」把整份列表再发成一条新评论。以后每次登录会自动读回评论区里你发过的所有集锦评论（合并去重显示）。**在 B 站把评论删了，云端那份就没了，本机列表不受影响。**工作室的「云端 / 他人集锦」区里能看到别人发的集锦，点「载入」才合并进播放列表。

**分享**：片段行右侧 `↗` 分享单个片段，「分享整场」分享整份列表。会生成一段 `VC1.` 开头的导入码，微信里发给朋友即可。朋友在微信里点开中转页可以唤起 App；微信拦 scheme 时，复制那串码 → 打开 VCNC足球 → 点 `＋制作` →「从剪贴板导入」就行，全程不依赖服务器。数据格式与微信跳转链路的完整方案见 [自定义集锦方案](docs/CUSTOM_CLIPS.md)。

### B 站账号、画质与三连

播放页左侧半透明浮窗是账号入口，不登录也能看见（显示「未登录」）。点「登录 / 授权」后：

1. 应用会**自动检测并拉起本机 B 站客户端**，直接打开授权页；在 B 站 App 里点一下「确认」再切回来就完成登录，**全程不用扫码**。若 B 站 App 自己还没登录，会先提示你在 App 里登录。未登录时也可以直接点标题后面的灰色「三连」，同样进登录流程。
2. 登录成功后浮窗那一行会变成你的头像和昵称，应用自动重新取流以刷新可用画质列表。
3. 画质档位**人人可切**：浮窗里点选 360P~1080P 不需要大会员；1080P60 / 高码率 / 4K 等大会员档同样可以点，B 站会自动下发你账号可见的最高档（未登录/非会员点 1080P60 实际会拿到较低画质，登录大会员后同档位即生效）。高亮显示的是实际播放画质，切换会记住当前播放进度并短暂重载。
4. 点标题后面的「三连」给**当前正在播放的这场 VCNC 视频**同时点赞、投币（默认 1 枚）和收藏到默认收藏夹；点完变「已三连」，换到点过的场次也会显示「已三连」，避免重复操作。

不方便用客户端时（例如桌面调试版），可展开登录弹层的「其他登录方式」复制授权链接或显示二维码；也可在弹层底部或设置页「登录 Cookie」里粘贴浏览器里的 `SESSDATA=…; bili_jct=…`，效果相同。想换账号：到设置页「B 站账号」一行点「退出登录」，只清本机凭证，**不会**把你在 B 站其它设备上的登录踢掉。

> **隐私**：B 站登录凭证只写在应用私有目录（Android）或本机用户目录（桌面调试版），不上传、不写日志、不进代码仓库；前端页面从不接触 `SESSDATA`。授权链接只在本机与 B 站之间传递，二维码由应用本地生成，不经过任何第三方服务。

## 流量与缓存

- 播放页**标题同一行的右侧**（紧挨「列表 / 设置」）常驻流量小卡，**一行显示**：实时速率 ｜ 本次 ｜ 累计。使用**移动数据**时变橙色并写明「移动」，提醒注意套餐；标题过窄时自动隐去「本次 / 累计」两个标签、只留三个数字。控制条自动隐藏时它也跟着淡出。
- 设置页「网络流量」给出三个口径：**当前速度**、**本次启动消耗**、**安装以来累计消耗**，以及**缓存已省下多少流量**；点「清零」只清统计数字，不删缓存文件。
- 只统计真正从网络下载的字节；命中本地磁盘缓存、以及 App 内部通信都不计入。
- **省流量用法**：第一次打开某场比赛时连 WiFi，让它把集锦片段缓存好；之后用移动数据甚至短时断网重看同一场，基本不再走流量。默认 600MB 足够留住近十场比赛的集锦数据。

## 常见问题

**提示「接口受限 / 风控中」，视频加载失败？**
这是 B 站对**出口 IP** 的限流（`-352 / -412 / HTTP 412`），不是网络坏了，也不是应用崩溃。按下面顺序试：

1. **登录 B 站账号**：左侧账号浮窗用本机 B 站 App 授权，或在设置里手填 `SESSDATA`。登录态的配额远高于游客，这是最有效的一招。
2. **换出口 IP**：WiFi ↔ 移动数据切一下；同一网络连着快速点很多场比赛最容易触发。
3. **等一会儿**：应用会自动拉起 30 秒起的冷却并显示剩余秒数，冷却期内不再向 B 站发包——连点「重试」不会让封锁更长，但也请按提示等一下。
4. **看过的比赛照常能播**：解析成功时应用会留一份快照，风控期间改从本地磁盘缓存播放；这类播放会提示「正在用本地缓存」，只有**没缓存过**的片段可能加载失败。想让某场完全离线可看，先在 WiFi 下完整播一遍让它把集锦片段缓存好。

列表页也一样：接口被限时自动沿用上次的比赛列表，不会变成空白页。

**画质按钮是灰的，或三连按钮是灰的？**
360P~1080P 的画质切换**不需要大会员**，未登录也能在浮窗里点选；B 站只把 1080P60 / 高码率 / 4K 等档位留给大会员——未登录或非会员点了这些档，B 站会静默下发可见的最高档（例如游客请求 1080P 实际拿到 480P）。浮窗高亮跟随实际播放画质。想看大会员档位，先在左侧账号浮窗（或直接点标题后面那个灰的三连）用 B 站 App 授权登录大会员账号，应用会自动重载一次刷新可用档位。若刚续费大会员，到设置页退出登录再授权一次即可刷新状态。

**列表里比赛不全？**
默认只加载第一页，滚到列表底部点「加载更多」。

**浮窗时间码和画面上的时钟对不上？**
B 站转码会把可变帧率重排成恒定帧率，烧录时钟与播放进度每小时会漂几秒。应用会自动做时间轴校准，并把浮窗标签显示成「起播那一刻画面上的时间」，所以两者本就不该是同一个数字；想微调可用设置里的前置/后置补时。

**画面卡住不动、只有声音？**
超高像素的折叠屏会自动切到单路解码模式；若仍异常，到设置里关掉「算法可视化」、把画面填充切回「完整」，或点「恢复完整显示」。

**装不上 / 更新下载失败？**
确认系统允许本应用「安装未知应用」，且用的是本仓库发布的同一签名 APK。下载线路会自动在官方资产、CDN、GitHub 接口之间回退，仍失败可直接在浏览器打开下载链接。
