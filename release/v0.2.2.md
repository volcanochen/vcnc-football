# VCNC 足球沉浸场 v0.2.2

**当前推荐版本**。修掉应用内升级链路上的最后一处设备兼容问题。

## 修复

v0.2.1 已能在受限网络下通过多源回退成功下载 APK（真机日志：
`github.com` 超时 → `cdn.jsdelivr.net` 下载 99,120 字节 → 进度 100%）。
但在装有 ES File Explorer 这类文件管理器的设备上，系统会把 `ACTION_VIEW` + APK MIME
弹成「打开方式」选择框；一旦用户选了第三方文件管理器，`content://` 授权拿不到，
安装根本不会发生，而且容易误以为是应用坏了。

`UpdateChecker.install()` 现在先查询能处理该意图的 Activity，
显式把组件指向系统的「软件包安装程序」（包名含 `packageinstaller`，
兼容 AOSP 与三星 ROM），不再弹选择框；查不到时仍退回隐式意图。

同时补充：下载写入前校验 APK 的 zip `PK` 头，避免错误页被当安装包。

## 完整升级链路（Note8 / Android 9 真机验证）

1. 设置 →「检查更新」→ 显示「发现新版本 x（当前 y）」与 Release 说明
2. 点「下载并安装」→ 多源回退下载，进度 0→100%
3. 直接拉起系统安装确认页 → 用户点「安装」→ 覆盖升级完成
4. 再次检查 →「已是最新版本 x」

> Android 8+ 首次升级需先在系统设置里允许本应用「安装未知应用」（应用会自动跳到该设置页）。

## 其余功能

VCNC 比赛流、集锦连播、焦点镜头与竖屏分屏放大镜、集锦分类、慢动作、
亮度/音量手势、冷启动续播、feed 缓存兜底，均与 v0.2.0 相同。
