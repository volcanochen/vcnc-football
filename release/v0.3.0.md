# VCNC足球 v0.3.0

**当前推荐版本**。本版是**B 站账号 + 社交**批次：应用内直接用本机 B 站客户端授权登录，
大会员可按需切画质，标题后面多了一个「三连」按钮；顺带把顶部一行重新排过，
并把手势改成「单击显隐浮窗 / 双击播放暂停」。播放引擎与倒放、缓存、流量统计沿用 v0.2.5。

## 新增

### B 站账号（左侧账号浮窗）
- 播放页左侧多了一条半透明账号浮窗：一行显示头像、昵称和收起箭头，下面是画质档位。
  不登录也能看见（显示「未登录」），不影响看球。
- **用 B 站 App 授权登录，全程不扫码**：点「登录 / 授权」后应用会自动检测并拉起本机
  B 站客户端，打开授权页，在 App 里点一下「确认」再切回来就登录好了。
  手机没装 B 站 App、或者不想用 App 时，浮窗里展开「其他登录方式」还能复制授权链接、
  看二维码，或手填浏览器里的 Cookie（桌面调试版同理）。
- **凭证只写在本机应用私有目录**：不上传、不写日志、不进代码仓库，前端页面从不接触
  `SESSDATA`。退出登录只清本机凭证，**不会**把你在 B 站其它设备上的登录踢掉。

### 大会员画质切换
- 登录后按视频实际可用的清晰度列出档位（1080P60 / 高码率 / 4K 等，取决于该视频本身），
  点一下切换，会记住当前播放进度并短暂重载。
- 非大会员时档位按钮是灰的并提示需要大会员——这是 B 站侧的权益限制：游客状态即便请求
  1080P，接口也只会给 480P。刚续费大会员的话，退出登录再授权一次即可刷新状态。

### 标题后的一键三连
- **三连按钮就贴在标题文字后面**，不再跑到屏幕右边：灰色＝未登录（点它直接进登录）、
  亮色＝已登录可点、粉色「已三连」＝这场已经投过了。
- 一份动作同时点赞、投币（默认 1 枚）和收藏到默认收藏夹，作用于**当前正在播放的这场**。
  点过的场次会记在本机，换场次按它自己的状态显示，避免重复投币。

## 变化

### 顶部一行重排
- **流量 HUD 回到一行**：实时速率、本次、累计三项横排，中间用细竖线分隔，数值一个不少。
  窄屏（标题会被挤到读不出字）时自动退一档：省掉「本次 / 累计」两个标签、
  显示成 `↓0B/s │ 279K/238M`，三个数字仍然都在，宽屏自动恢复。
- **三连按钮紧跟标题**：以前副标题比标题长，会把按钮顶到最右；现在按钮和标题关在同一行里，
  永远贴住标题最后一个字。
- 播放键比其他键大一圈；倒放键与播放键之间留了空隙，避免误触。

### 手势调整
- **单击画面 = 显示 / 隐藏浮窗**，想让它立刻消失点一下就够。
- **双击画面 = 播放 / 暂停**。双击后有约 0.26 秒的判定窗口，所以双击暂停不会把浮窗闪出来。
- 控制条自动隐藏从 1.8 秒放宽到 **4.5 秒**——既然点一下就能收起，自动隐藏只当兜底，
  手停在屏幕上也别急着消失。

## 安装 / 升级

下载本页 `VCNC-Football-v0.3.0.apk` 覆盖安装，或在应用内点「设置 → 软件更新 → 检查更新」升级。
与之前所有版本**同一签名**，可直接覆盖。
Android 8 及以上首次安装需允许本应用「安装未知应用」。

包名 `com.vcncfootball`，versionCode 8 / versionName 0.3.0，minSdk 24 / targetSdk 34，V3 签名。
校验和见仓库 `release/SHA256SUMS.txt`。源码与文档：<https://github.com/volcanochen/vcnc-football>

## 验证

- **发布门禁全绿**：版本一致性 / 源码语法与 Chrome 74 兼容红线 / 品牌与三语言资源 /
  APK 内容与签名 / 文档链接 / 两端流量与社交接口对齐，静态检查全部通过。
- **双机真机**：SM-S9080（S22U）与 SM-N9500（Note8）标准回归各 **19/19**；
  `_test/verify_social.js`、`_test/verify_top_row.js`、`_test/verify_tap.js` 三条专项双机全绿
  （含物理 `input tap` 单击隐藏 / 双击暂停且浮窗保持隐藏的实测）。
- **免设备回归**：`_test/verify_qr_matrix.py` 自研二维码与标准库矩阵逐点一致（32/32）；
  `_test/verify_social_api.py` 端点冒烟通过（真实二维码、跨站 POST 拒绝、假凭证过期识别）。
- **未覆盖**：真实点「确认」完成授权、大会员高画质播放与真实三连投币属于账号本人操作，
  发版验证时只确认了「链路可达 + 未登录时的降级状态正确」。

## 已知限制

- S22U（400px 宽）顶部一行要同时放标题、三连、HUD 和「列表 / 设置」，标题只剩约 6 个字的宽度
  就出现省略号；Note8（412px）稍宽一些。如果需要长标题完整可见，下一版可以把 HUD 单独挪一行。
- 授权的「确认」页由 B 站 App 提供，页面文案会是「哔哩哔哩扫码登录」——那是 B 站 H5 的固定标题，
  实际操作是点确认，不需要扫码。
