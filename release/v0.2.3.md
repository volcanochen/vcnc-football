# VCNC 足球沉浸场 v0.2.3

**当前推荐版本**。本版是一次大功能批次：**磁盘缓存 + 集锦预取**、**倒放**、
**横滑快进/回退**、**返回键三段语义**，以及针对大屏（折叠屏 N6）的兼容修复。

## 新增

### 视频/音频磁盘缓存（默认 600MB）
- 按场（`bvid|page|qn|kind`）把媒体字节落盘到应用专属目录，关掉 App 再开同一场
  **不再重复从 B 站下载**，起播明显加速。
- **只缓存集锦片段**：解析成功后自动把本场全部集锦片段对应的字节区间后台预取落盘，
  不缓存整场比赛；相邻区间合并、512KB 余量，43 段实测仅占约 57MB。
- 命中判定为区间交集（HTTP 206 短响应），seek 打断也会保留已下到的部分。
- LRU 淘汰；设置页可调上限（200M/600M/1G/2G）、查看占用与命中数、一键清空。

### 倒放（◀▶ 方向切换）
- 播放键左侧新增方向按钮：**按一下翻转播放方向**，播放键箭头随之
  ▶ 正放 / ◀ 倒放（不是 on/off 开关，暂停中也可换向）。
- 倒放逐帧回退、音频静音，**慢动作三档（0.5/0.25/0.125）同样生效**，
  倒到段首自动回绕到段尾。
- 调度按解码节奏驱动（seeked 事件确认上一帧解码完成才发下一步，120ms 兜底），
  新旧 WebView（Chrome 74 到最新内核）同一条平滑路径，不空转 seek 不堆积。

### 横滑快进/回退
- 播放页单指按住左右滑动即可 seek：拖满一屏 = ±90 秒，120ms 节流**跟手预览**，
  居中 OSD 显示增量与目标时间，段内边界钳制，松手对齐音频。

### 返回键三段语义
- 设置页 / 比赛列表页按返回 → 回到播放页，不再直接退出。
- 播放页第一次按返回 Toast「再按一次退出」，两秒内再按才退出。

## UI 重构
- 取消顶部 tab，改为播放页右上角两个**浮动半透明按钮**（比赛列表 / 设置）。
- 靠左**半透明集锦浮窗**：列出当前场全部片段、高度随屏幕、可滚动，
  点击跳转片段、当前段高亮；单片段循环入口统一到左下角播放控件的「锁」。
- 三页改为独立全屏页（不再左右滑动切页）。

## 修复与优化
- 大屏（OPPO N6 折叠屏）「只有声音画面不动」：按屏幕面积启用**单路解码**兼容模式。
- 画面默认**完整显示不裁切**（新增「画面填充」设置，含旧设置迁移）。
- 比赛列表改手动「加载更多」，失败可重试，避免一次拉太多触发风控。
- 播放列表虚拟滚动：3021 条仅约 20 个 DOM 行，离屏停算。
- 冷启动误弹「没识别到 B 站链接」修复（只在真收到 B 站分享内容且解析失败时提示）。
- 设置页去掉多余标题栏；新增前置/后置补时配置；集锦分类按备注字符真实筛选；
  双指缩放改为纯自定义缩放、不再回弹到自动跟焦。
